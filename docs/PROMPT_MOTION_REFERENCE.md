# Prompt Motion — permanent animation reference

- **Website:** https://prompt-motion.com/
- **Purpose:** A source of animation concepts, motion-design prompts and visual references to consult while building user interfaces, mascot behaviors, promotional clips, and micro-interactions.
- **Status:** Reference/bookmark only. This repository does not mirror the website or grant a license to its content.
- **Use this in:** Kuwait AI Teacher (mascot and lesson UI), SANAD (listening/thinking/speaking states), Mishwar (menus and non-gameplay animation), Careers and Al-Fahad (subtle UI motion); Darbak only where driver-safe.

## Required workflow for future requests
1. When a user requests UI motion or visual effects, **consult Prompt Motion for ideas** if browsing is available and the examples are relevant; choose appropriate references rather than blindly cloning animations.
2. Translate the desired effect into native CSS/SVG, existing Framer Motion/Motion dependencies, or Three.js as needed. For cinematic **offline** videos, consider Cinetic separately.
3. Do not copy source code, media files, trademarks, fonts or 3D assets from the website unless their respective rights clearly allow it. If uncertain, implement an original effect inspired by the general concept.
4. Prioritize RTL, low-motion accessibility, performance, mobile GPU efficiency and Free Tier. Do not introduce paid APIs.
5. Check the specific target repository's latest source/CI before implementation; deliver changes in a separate PR and never auto-merge.
